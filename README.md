# SBS Lab

Минималистичная веб-платформа для разметки TTS: бинарные аудио-вопросы («да / нет / не разобрать»), попарное A/B-сравнение, роли администратора и разметчика, контрольные задания (ханипоты).

Задания, пользователи и ответы живут в SQLite на сервере: команда работает одновременно, каждый разметчик заходит по персональной ссылке.

## Возможности

- бинарные вопросы «да / нет / не разобрать» по одному аудио;
- попарное A/B-сравнение с вариантом «равноценны»;
- быстрые клавиши `1`, `2`, `0`, `←`, `→`;
- ответ уходит на сервер сразу, карта прогресса, переход назад и вперёд;
- вход по персональной ссылке, роли администратора и разметчика;
- контрольные задания с эталонным ответом и точностью по каждому разметчику;
- регулируемое перекрытие `1–7`, очередь выдаётся сервером;
- консенсус по большинству голосов и agreement с большинством остальных;
- импорт заданий из JSONL, выгрузка результатов в JSON и CSV;
- слепая разметка нескольких партий: источник аудио скрыт от разметчика;
- адаптивный интерфейс для ноутбука и телефона.

## Роли и перекрытие

Администратор видит задания, команду, контрольные задания, статистику и настройки;
разметчик — только свою очередь и личный прогресс.

При перекрытии `3` задание выдаётся, пока по нему не наберётся три ответа, после чего оно
выходит из очередей. Итогом становится самый частый ответ; если лидеры набрали одинаковое
число голосов, результат помечается как спорный. Контрольные задания из этого правила
исключены — их видит каждый разметчик.

Agreement считается аккуратнее: для каждого ответа пользователя берётся большинство **остальных** ответивших. Собственный голос не участвует в определении эталона; случаи без большинства пропускаются.

## Запуск

Фронтенд и API поднимаются раздельно: Vite собирает статику, FastAPI её раздаёт.

```bash
npm install && npm run build          # соберёт dist/

uv venv venv && uv pip install --python venv/bin/python fastapi uvicorn
LABELER_DB=./data/labeler.db \
LABELER_DIST=./dist \
LABELER_AUDIO_ROOTS=./media \
  venv/bin/uvicorn app:app --app-dir server --host 0.0.0.0 --port 8888
```

Для разработки фронтенда `npm run dev` по-прежнему работает — добавьте прокси на API в `vite.config.ts`.

## Администрирование

Всё, что делает UI, доступно и в CLI (`server/cli.py`):

```bash
cli.py add-user "Имя"                 # создать разметчика и выдать персональную ссылку
cli.py users                          # список ссылок
cli.py import --predictions p.jsonl \
  --bucket brand_mfk --audio-root ./wav \
  --batch prod --media-dir ./media \
  --focus-field metrics.focus.reference \
  --question "Имя произнесено правильно?"   # импорт заданий
cli.py spread-batch prod --key groups.category --min-gap 4
cli.py suggest-honeypots --count 15 \
  --batch prod --apply --exclusive    # отобрать контрольные
cli.py batches                        # какие партии загружены
cli.py drop-batch prod                # удалить партию с её медиа
cli.py controls                       # статус эталонов
cli.py export --csv -o results.csv    # выгрузка
cli.py stats                          # сводка
```

### Контрольные задания (ханипоты)

Ханипоты не берутся из рабочих заданий — иначе часть корпуса «сгорает» под контроль.
Вместо этого грузится отдельный калибровочный набор:

```bash
cli.py import ... --batch hp-a --control   # задания только для админа
cli.py arrange-controls --min-gap 6        # развести дубли одного текста
#   → человек проставляет эталоны в разделе «Контроль»
cli.py promote-honeypots --count 15        # отобрать и подмешать разметчикам
```

Задание с `is_control = 1` **никогда** не попадает в очередь разметчика: оно видно только
администратору в разделе «Контроль». В очередь его добавляет `promote-honeypots`, которое
берёт поровну «да» и «нет» из размеченных и выбрасывает «не разобрать» — неоднозначный клип
контролем быть не может. Отобранные показываются каждому разметчику вперемешку с обычными
(по умолчанию одно на семь, настройка `honeypot_every`), а точность видна в колонке «Контроль»
на вкладке «Разметчики».

Порядок клипов внутри набора задаёт одна из двух команд — что правильно, зависит от задачи:

- `arrange-controls --min-gap 6` разносит дубли одной реплики подальше. Нужно для калибровки
  ханипотов: рядом стоящие дубли человек начинает сравнивать между собой вместо того, чтобы
  оценивать каждый клип отдельно.
- `cluster-controls` наоборот ставит все варианты одной реплики подряд (порядок вариантов
  внутри перемешан). Нужно для A/B наборов, где сравнивают именно произношение, а не тексты.

Что считать «одной репликой», задаётся при импорте: `--phrase-key text` (по умолчанию) или
`--phrase-key id-tail`, если у вариантов намеренно разный текст.

Наборы разделены заголовками: `--control-group "Написания «МФК»"` даёт подпись, безопасную
для показа. Название варианта и партии живут только в `meta`; в интерфейсе клип обозначен
непрозрачным кодом, а вопрос задаётся на партию через `--question`.

### Слепая разметка нескольких партий

`--batch <имя>` добавляет метку партии в `id` и `meta`, а `--media-dir` копирует wav под
обезличенным именем (`sha1(batch|id)`). Разметчик видит только текст и аудио, поэтому можно
загрузить несколько партий одних и тех же фраз — источник останется скрытым.

## Очередь и перекрытие

Очередь формируется сервером на лету: задание выдаётся, пока по нему не наберётся
`requiredAnnotations` ответов. Каждый разметчик начинает с собственного смещения
(хеш от его id), поэтому параллельные работники не толпятся на первых заданиях.

Ханипот подмешивается только к заданиям с **тем же вопросом**: в череде заданий про числа
контрольное про бренд выделялось бы само по себе. Внутри своего блока они расставлены
равномерно, чтобы поместились все.

`spread-batch --key groups.category` перемешивает партию так, чтобы соседние задания
не повторяли один и тот же признак — одну компанию, одну категорию чисел.

## Что проверяем в задании

Если вопрос про часть реплики (имя, число, название компании), при импорте укажите
`--focus-field metrics.focus.reference`. Разметчик увидит проверяемый фрагмент крупно,
а полную реплику — под ним как контекст. Без этого поля показывается только реплика.

## Формат датасета

Задания импортируются из JSONL предсказаний (`cli.py import`). Внутри они хранятся в том же
виде, что понимает фронтенд:

```json
{
  "project": "Эксперимент #42",
  "defaultOverlap": 3,
  "tasks": [
    {
      "id": "sbs-001",
      "type": "pairwise",
      "text": "Текст для озвучивания",
      "question": "Какой вариант звучит естественнее?",
      "requiredAnnotations": 3,
      "audioA": { "src": "/audio/a.wav", "label": "Model A" },
      "audioB": { "src": "/audio/b.wav", "label": "Model B" }
    },
    {
      "id": "intonation-001",
      "type": "boolean",
      "text": "Это вопрос?",
      "question": "Есть ли вопросительная интонация?",
      "requiredAnnotations": 3,
      "audio": { "src": "/audio/question.wav", "label": "Model A" }
    }
  ]
}
```

`src` указывает на `/audio/<абсолютный путь>`; сервер отдаёт файл, только если путь лежит
внутри `LABELER_AUDIO_ROOTS`. Для нового типа задания добавьте TypeScript-тип в `src/types.ts`,
renderer в `src/components` и разрешённые значения ответа в `BOOL_VALUES` / `answer()` на бэкенде.

## API

| метод | путь | кто | зачем |
|---|---|---|---|
| GET | `/api/bootstrap` | все | проект, очередь заданий, свои ответы |
| POST | `/api/answer` | все | сохранить ответ |
| POST | `/api/control` | админ | задать эталон ханипота |
| POST | `/api/control/flag` | админ | пометить/снять контрольное |
| GET/POST | `/api/users` | админ | список со ссылками / создать |
| GET | `/api/quality` | админ | точность по ханипотам |
| GET | `/api/export?format=json\|csv` | админ | выгрузка результатов |
| GET | `/healthz` | все | статус |

Авторизация — непрозрачный токен в заголовке `X-Token` или в ссылке `/?t=<токен>`;
фронтенд убирает его из адресной строки и хранит в `localStorage`.
