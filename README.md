# SBS Lab

Минималистичная веб-платформа для SBS-разметки TTS: сравнение двух аудио и бинарные аудио-вопросы. Работает полностью в браузере, не требует сервера и сохраняет прогресс в `localStorage`.

## Возможности

- попарное A/B-сравнение с вариантом «равноценны»;
- вопросы «да / нет / не уверен»;
- быстрые клавиши `1`, `2`, `0`, `←`, `→`;
- автосохранение, карта прогресса, переход назад и вперёд;
- импорт заданий и экспорт результатов в JSON;
- адаптивный интерфейс для ноутбука и телефона;
- расширяемая TypeScript-модель заданий.

## Запуск

```bash
npm install
npm run generate:audio
npm run dev
```

Сборка для публикации:

```bash
npm run build
npm run preview
```

## Формат датасета

Готовый пример лежит в [`public/tasks.example.json`](public/tasks.example.json). В интерфейсе нажмите `···` → «Импорт задач» и выберите JSON.

```json
{
  "project": "Эксперимент #42",
  "tasks": [
    {
      "id": "sbs-001",
      "type": "pairwise",
      "text": "Текст для озвучивания",
      "question": "Какой вариант звучит естественнее?",
      "audioA": { "src": "/audio/a.wav", "label": "Model A" },
      "audioB": { "src": "/audio/b.wav", "label": "Model B" }
    },
    {
      "id": "intonation-001",
      "type": "boolean",
      "text": "Это вопрос?",
      "question": "Есть ли вопросительная интонация?",
      "audio": { "src": "/audio/question.wav", "label": "Model A" }
    }
  ]
}
```

`src` может быть абсолютным URL или путём к файлу на том же хосте. Для нового типа задания добавьте TypeScript-тип в `src/types.ts` и отдельный renderer в `src/components`.
